# In-game screenshots

These are actual RimWorld 1.6 renders captured from an isolated staged save with Elemental Hearts, the installed DLC and optional Melee Animation. DLC is not required by Elemental Hearts. These are not generated concept art or composited apparel previews.

The roster uses adult Male bodies for consistent comparison, with current kits transformed and drafted. Combat opponents have test durability so effects can be photographed; the scenes are not damage/balance benchmarks. Images capture the native map camera without interface overlays. Regular colony saves/configuration are not used or altered.
