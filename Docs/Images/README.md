# Images and provenance

The native scene images listed below are actual RimWorld 1.6 renders captured from an isolated staged save with Elemental Hearts, the installed DLC and optional Melee Animation. DLC is not required by Elemental Hearts. These are not generated concept art or composited apparel previews.

The roster uses adult Male bodies for consistent comparison, with current kits transformed and drafted. Combat opponents have test durability so effects can be photographed; the scenes are not damage/balance benchmarks. The original four roster/combat scenes capture the native map camera without interface overlays. The additional Thunderfall capture includes the game interface and reflects its capture build. Regular colony saves/configuration are not used or altered.

| File | Scene |
| --- | --- |
| `01-lineage-roster.png` | Five ordinary elements, five evolutions, then Lunar/Eclipse/Celestial. |
| `03-solar-combat.png` | Heavenly Zenith. |

Native capture files are included directly. Temporary screenshot/test assemblies and saves are excluded from the playable mod.
