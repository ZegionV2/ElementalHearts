# Phase 4.4 — short Lightning hair

Adds a simpler short male hairstyle: charcoal hair, compact swept forelock and one blue streak. Three transparent directional textures; west mirrors east. The original long style is retained.

Select an implanted pawn, then Lightning hair → Short lightning hair. The same menu offers Original lightning hair and Restore previous hairstyle. Switching between Lightning styles retains the original hairstyle for restoration. Implant removal also restores it. The new style is tagged Male for native style selection; the explicit cosmetic menu remains available on implanted player pawns.

Both Lightning hairstyles use fixed artwork colors, independent of the pawn's natural color, dye or graying. The pawn's stored hair color is not changed, so other hairstyles still use it normally. Other hair mods and non-Lightning hair are not recolored.

Generated using the built-in image tool. Original sheet and full prompt are provided beside the mod in LightningVFX-Concepts. The generated art was cropped/resized to 256×256 transparent game textures. All Phase 4.3 abilities, sounds, recovery and cooldowns remain included.

Close RimWorld and replace the previous ElementalHearts folder, keeping only one copy. The installed mod was not overwritten. Standard pawn rendering is checked; modded heads and animation renderers may need separate fitting.
